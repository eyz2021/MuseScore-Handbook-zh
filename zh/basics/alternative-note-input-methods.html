其他音符输入方法

使用其他音符输入方法

除了默认的 步进输入 方式外，MuseScore 还提供其他几种输入记谱的方式。

要进入这些其他音符输入方法：

  1. 在 音符输入工具栏 中，按住 音符输入 按钮不放。
  2. 从可用的音符输入方法中选择一种。

键盘用户可以从乐谱处按几次 Shift+Tab 或 Shift+F6 定位到 音符输入 按钮。屏幕阅读器会读出类似 “音符输入工具栏：默认（步进）” 的内容。在该按钮上按 Space 键会打开一个包含所有可用音符输入方法的菜单。

每种音符输入模式也可以直接通过指定的键盘快捷键激活（学习如何指定快捷键请参阅 键盘快捷键）。

注意：即使你退出了音符输入模式，所选的音符输入方法仍会保持有效，并在下次进入音符输入模式时启用。因此，如果你只为某一段乐句改用了 重写音高 方法，完成后记得改回 步进输入 方法。

仅节奏

节奏 音符输入方法允许你通过单次按键输入时值。这对于使用单一音色的无音高打击乐器尤其有用。此外，在某些情况下，你可以结合 节奏 和 重写音高 方法，实现高效的工作流程。

  1. 在乐谱中选择起始位置。
  2. 按上文所述选择 节奏 音符输入方法。
  3. 从音符输入工具栏中选择一个时值，或使用快捷键 1-9，以输入一个所选时值的音符。
  4. 按 . 并选择/键入你想要的时值，可输入附点时值。在此模式下，附点会在之后所有输入时值上切换开/关。值得注意的是，附点需要在输入音符时值之前激活，而不是之后。
  5. 单击音符输入工具栏中的休止符图标并选择/键入想要的时值，即可输入休止符。如果想要的时值已经（从上一个输入的音符）选中，按 0 即可输入休止符。再次单击休止符按钮可返回输入音符。
  6. 继续按时值键，以输入所选时值的音符。

默认情况下，音符会输入到谱表中间的线上。你可以使用方向键修改刚输入音符的音高，后续音符也将使用该音高输入。你也可以在输入节奏后使用 重写音高模式 快速为一段乐句输入音高。

重写音高

重写音高 音符输入方法允许你修改一串音符的音高，同时保持其时值不变。

  1. 在乐谱中选择起始位置。
  2. 按上文所述选择 重写音高 音符输入方法，或使用快捷键 Ctrl+Shift+I（Mac：Cmd+Shift+I）。
  3. 使用电脑键盘、MIDI 键盘或 虚拟钢琴键盘 输入音高。注意：在 重写音高 方法中，你不能使用鼠标输入音符。

重写音高 方法是输入节奏型重复音乐的高效方式。只需复制粘贴一段与你新乐句节奏相同的现有乐句，再使用重写音高模式修改音高即可。同样的技巧也可用于输入共享相同节奏但音高不同的多个器乐或声乐声部。

实时输入

实时音符输入方法基本上允许你在 MIDI 键盘（或 MuseScore 的 虚拟钢琴键盘）上演奏乐曲，并让记谱自动为你添加。不过，你需要注意以下目前适用的限制：

  • 你必须预先选择想使用的最短时值。
  • 你无法在 实时 音符输入中输入连音。
  • 与其他音符输入模式一样，你必须在单个谱表和单个声部中输入音符。
  • 实时 音符输入无法使用电脑键盘。

这些限制意味着 MuseScore 在判断你的输入应如何记谱时几乎无需猜测，从而有助于保持这些方法的准确性。

实时（节拍器）

使用 实时（节拍器） 音符输入方法时，你以节拍器咔哒声指示的固定速度演奏。你可以通过更改菜单中咔哒声之间的延迟来调整速度：编辑→偏好设置...→音符输入（Mac：MuseScore→偏好设置...→音符输入）。

  1. 在乐谱中选择起始位置。
  2. 按上文所述选择 实时（节拍器） 音符输入方法。
  3. 从音符输入工具栏中选择一个时值来代表节拍器的咔哒声。
  4. 按住一个 MIDI 键或虚拟钢琴键，输入所选时值的音符。
  5. 聆听节拍器的咔哒声——每响一次，音符就按所选时值增长。
  6. 当音符达到所需长度时松开琴键。

松开琴键后，乐谱立即停止前进。如果你想让乐谱继续前进（输入休止符时需要），可以使用 实时前进快捷键 启动节拍器。再次执行同一操作即可停止节拍器。

实时（脚踏板）

使用 实时（脚踏板） 音符输入方法时，你通过敲击琴键或踏板来指示输入速度。你可以以任意速度演奏，且无需保持恒定。设置速度的默认键（称为“实时前进”）是数字小键盘上的 Enter（Mac：Fn+Return），但强烈建议你将其改为 MIDI 键或 MIDI 踏板（见下文）。

  1. 在乐谱中选择起始位置。
  2. 按上文所述选择 实时（脚踏板） 音符输入方法。
  3. 从音符输入工具栏中选择一个时值来代表节拍器的咔哒声。
  4. 按住一个 MIDI 键或虚拟钢琴键。
  5. 每按一次“实时前进”快捷键，音符就按所选时值增长一次。
  6. 当音符达到所需长度时松开琴键。

实时前进快捷键

“实时前进”快捷键用于在 实时（节拍器） 方法中启动节拍器，或在 实时（脚踏板） 方法中打拍子。它之所以称为“实时前进”，是因为它会使输入位置在乐谱中向前移动，即“前进”。

实时前进的默认键是数字小键盘上的 Enter（Mac：Fn+Return），但强烈建议你通过 MuseScore 的 MIDI 远程控制将其指定给一个 MIDI 键或 MIDI 踏板。MIDI 远程控制可从菜单 编辑→偏好设置...→MIDI 映射（Mac：MuseScore→偏好设置...→MIDI 映射）中访问。

或者，如果你有可以模拟键盘按键的 USB 脚踏开关或电脑踏板，也可以将其设置为模拟数字小键盘上的 Enter 键。

插入

插入 音符输入方法允许你在小节内插入和删除音符与休止符，并自动让后续音乐在小节内向前或向后移动。小节时值 会随着你的操作自动更新。

要插入一个音符：

  1. 在乐谱中选择起始位置。
  2. 按上文所述选择 插入 音符输入方法。
  3. 像在 步进输入 模式中一样输入音符或休止符。每个音符都会插入到当前光标位置之前，小节时值会相应增加。

音符输入后会放置在被选起始元素之前，该元素会用蓝色方块标记高亮显示。起始元素以及同一小节内其后的任何音符或休止符都会向前移动。你可以使用 Right 或 Left 方向键前后移动插入点，新的插入点会高亮显示。

或者，如果只需插入一两个音符，可以直接使用默认的 步进输入 音符输入方法。用鼠标或键盘快捷键（A-G）添加音符时按住 Ctrl+Shift（Mac：Cmd+Shift）。

要插入休止符，先插入一个所需时值的音符，然后按 Backspace 或 Del。

要删除音符或休止符，使用快捷键 Ctrl+Del（Mac：Cmd+Backspace）。小节时值会相应减少。该快捷键在 步进输入 和 插入 音符输入方法中都有效。

由于插入音符可能导致小节时值超出拍号规定的范围，发生这种情况时，小节上方会显示一个小“+”或“-”号。
