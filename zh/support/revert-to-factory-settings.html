恢复出厂设置

概述

如果应用程序的偏好设置已损坏，可能需要重置 Musescore 应用程序偏好设置。这会删除自定义面板和自定义键盘快捷键，并清除文件菜单和主页选项卡下的最近乐谱链接：乐谱，但不会删除任何乐谱文件。

在操作前，欢迎咨询 https://musescore.org/en/forum 上的志愿者。请自行斟酌操作，Muse Group 和在线社区对任何数据丢失不承担责任。

从菜单恢复出厂设置

  1. 选择 帮助→恢复出厂设置。
  2. 选择 恢复 进行重置。
  3. 选择 重启 重启应用程序。

从命令行恢复出厂设置

如果 MuseScore 无法启动，您必须通过命令行运行此过程。

Windows

来源：https://musescore.org/en/node/342982

  1. 如果 MuseScore 已打开，您需要先关闭它（文件→退出）
  2. 输入 Win+R 打开“运行”对话框。或者用鼠标选择“开始”并输入“run”，然后单击“运行”程序。
  3. 单击 浏览...
  4. 在计算机上查找 MuseScore4.exe。位置可能因安装而异，但可能类似于 我的电脑 → 本地磁盘 → Program Files → MuseScore 4 → bin → MuseScore4.exe
  5. 单击 打开 离开“浏览”对话框并返回“运行”对话框。以下文本（或类似内容）应显示在“运行”对话框中

C:\Program Files\MuseScore 4\bin\MuseScore4.exe\ 或\ %ProgramFiles%\MuseScore 4\bin\MuseScore4.exe

对于 Windows Store 版本（Windows 10），它隐藏得相当深，请通过 Windows 资源管理器搜索

  1. 在引号后单击，并添加一个空格，后跟一个连字符和大写 F：-F
  2. 按 确定

几秒钟后，MuseScore 应该会启动，并且所有设置恢复为“出厂设置”。

对于高级用户，

主偏好设置文件位于：\ C:\Users\[用户名]\AppData\Roaming\MuseScore\MuseScore4.ini\ 或\ %APPDATA%\MuseScore\MuseScore4.ini

最近列表位于：\ C:\Users\[用户名]\AppData\Local\MuseScore\MuseScore4\recent_files.json\ 或\ %LOCALAPPDATA%\MuseScore\MuseScore4\recent_files.json

其他偏好设置（面板、会话、快捷键、工作区、日志等）位于：\ C:\Users\[用户名]\AppData\Local\MuseScore\MuseScore4\\ 或\ %LOCALAPPDATA%\MuseScore\MuseScore4\

对于 Windows Store 版本（Windows 10），这些隐藏得相当深，请通过 Windows 资源管理器搜索

macOS

本节（macOS）下的说明未经测试，截至 2023 年 10 月，网上尚未找到 Musescore 4 特定的 macOS 测试结果，以下内容改编自 Musescore 3 https://musescore.org/en/handbook/3/revert-factory-settings。请测试、纠正错误并移除此段。

  1. 如果 MuseScore 已打开，您需要先退出应用程序（MuseScore→退出）
  2. 打开终端（在 应用程序/实用工具 中，或通过聚焦搜索），应出现一个会话窗口
  3. 在终端行中键入（或复制/粘贴）以下命令（包括开头的 '/'）：

/Applications/MuseScore\ 4.app/Contents/MacOS/mscore -F

这会将所有 MuseScore 偏好设置重置为出厂设置，并立即启动 MuseScore 应用程序。请注意，不退出 MuseScore 就无法退出终端。您可以安全地退出 MuseScore、退出终端，然后以正常方式重新打开 MuseScore，继续使用。\ 对于高级用户，MuseScore 主偏好设置文件位于 ~/Library/Preferences/org.musescore.MuseScore4.plist。通常，删除此文件无效：macOS 会在某个未知位置存储设置的缓存副本。正确删除此文件的方法是，在终端应用中运行以下命令：\ defaults delete org.musescore.MuseScore4

其他偏好设置（面板、会话、快捷键、工作区、日志等）（这些不会被 macOS 缓存。）位于\ ~/Library/Application\ Support/MuseScore/MuseScore4/

Linux

来源：https://musescore.org/en/node/345932

以下内容适用于 Ubuntu，并且很可能适用于所有其他 Linux 发行版和 UNIX 风格的操作系统。

  1. 如果 MuseScore 已打开，您需要先退出应用程序（文件→退出）
  2. 从 Ubuntu 主菜单选择 应用程序→附件→终端。应出现一个终端会话窗口
  3. 在终端行中键入（或复制/粘贴）以下命令（在终端中粘贴用 Ctrl+Shift+V）：

mscore -F\ 或\ musescore -F\ 或\ mscore4portable -F\ 或者，如果您使用的是 AppImage 版本，请使用 cd 命令切换到保存 AppImage 的位置。例如，如果您将其保存到桌面（且只有一个）：\ cd ~/Desktop\ ./MuseScore*.AppImage -F

这会将所有 MuseScore 偏好设置重置为出厂设置，并立即启动 MuseScore 应用程序。您现在可以退出终端，继续使用 MuseScore。

对于高级用户，

MuseScore 主偏好设置文件位于\ ${XDG_CONFIG_HOME:-~/.config}/MuseScore/MuseScore4.ini

其他偏好设置（面板、会话、快捷键、工作区、日志等）位于\ ${XDG_DATA_HOME:-~/.local/share}/MuseScore/MuseScore4/
