无障碍功能

屏幕阅读器

MuseScore Studio 支持 Windows 上的 NVDA 和 macOS 上的 VoiceOver。目前不支持 JAWS。对其他屏幕阅读器的支持程度各不相同。

Windows 上的语音朗读

如果 MuseScore 中的语音朗读无法工作，请尝试按下 Alt+F 聚焦到文件菜单，然后按两次 Esc 返回到您在程序中的位置，此时屏幕阅读器应能重新开始工作。如果您是在 MuseScore 已经运行之后才启动屏幕阅读器，通常需要进行此操作。

如上所述，MuseScore 通过 JAWS 输出的语音目前不如通过 Narrator 或 NVDA 那样完整。

macOS 上的语音朗读

要在 macOS 上正确使用 VoiceOver 进行导航，您必须按如下方式进行配置：

  1. 在 VoiceOver 运行期间，同时按下 Left 和 Right 方向键，或通过 VoiceOver 实用工具 -> 指挥器，关闭快速导航模式。
  2. 在 VoiceOver 实用工具 -> 导航中，将鼠标指针设置为忽略 VoiceOver 光标。

MuseScore 的界面既可以使用 Tab 光标导航，也可以使用 VoiceOver 自带的光标导航。一般来说，最好使用 Tab 光标，因为它与其他平台上的界面一致，因此您在大多数文档和教程中看到的描述都是基于此。使用 Tab 光标时，请记住同时使用方向键和 Tab 键，如浏览用户界面中所述。VoiceOver 的光标可用于访问 Tab 光标尚无法到达的应用程序区域。

Linux 上的语音朗读

在 Linux 上，必须在启动 MuseScore 之前先启动屏幕阅读器，否则为了节省系统资源，无障碍功能将被禁用（Linux 上的所有 Qt 应用程序都是如此）。如果您忘记这样做，只需退出 MuseScore 并在屏幕阅读器运行的情况下重新启动即可。

Orca 是 Linux 上功能最齐全的屏幕阅读器。Orca 内置于 GNOME 桌面环境中，因此建议有无障碍需求的 Linux 用户使用基于 GNOME 或其衍生版本的发行版。

键盘访问

浏览用户界面

MuseScore 的 UI（用户界面）有一套分层级的键盘导航系统，这与您在其他应用程序中可能习惯的方式不同。在 MuseScore 的系统中，Tab 键会跳过部分控件以节省时间。如果您想到达这些控件，则需要同时使用方向键和 Tab 键。

快捷键 操作
F6 / ` / Shift+F6 / Shift+` 在 UI 各区域之间移动（` 是反引号或重音键，位于大多数 QWERTY 键盘的 Tab 键或左 Shift 附近）。
Tab / Shift+Tab 在控件组之间移动。
Up / Down / Left / Right 在同一组内的控件之间移动。
Esc 停止与可编辑文本控件的交互（这样您就可以用方向键从其中移开）。
Enter / Return 激活当前控件。
Space 激活当前控件或在列表中选中某一项。

请注意，UI 导航快捷键是固定的，无法更改，这与乐谱导航快捷键不同，后者可以在偏好设置中自定义。

浏览乐谱

以下快捷键对无障碍用户特别有价值：

快捷键 操作
Right / Left 移动到下一个或上一个音符、和弦或休止符。
Alt+Right / Alt+Left 移动到下一个或上一个元素。这些快捷键使您可以访问各种类型的记谱元素，而不仅仅是音符和休止符。
Alt+Up / Alt+Down 移动到上方或下方的音符。这些快捷键使您可以在和弦中的各个音符之间移动，还可以到达其他声部和其他谱表中的音符与休止符。
F2 / Alt+Shift+E 编辑所选元素。相当于用鼠标双击。可用它来编辑文本对象，或调整力度变化线、连音线和反复跳房子的长度（使用 Tab 键切换您正在调整的线条端点）。编辑完成后，按 Esc 返回普通模式。
Menu / Shift+F10 打开所选元素的上下文菜单。相当于用鼠标右键单击。它提供了多种选项，具体取决于所选元素。对范围选择使用此快捷键可访问小节属性以及谱表/分谱属性。

键盘导航的其他方面在本手册的各页中均有描述。所有乐谱导航和操作快捷键都可以在偏好设置中自定义。
