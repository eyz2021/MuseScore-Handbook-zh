下载与安装

要免费下载 MuseScore Studio（无需账户或订阅），请按照下面针对你具体操作系统的说明操作。

Windows

  1. 前往 musescore.org
  2. 单击标有免费下载的按钮

macOS

  1. 前往 musescore.org
  2. 单击标有免费下载的按钮

一个名为 MuseHub 的应用程序将安装到你的默认下载目录（通常是“下载”文件夹）。此应用程序可让你轻松安装 MuseScore Studio，以及一系列可大大增强你音乐创作体验的音色库和效果插件。

要安装并打开 MuseHub：

  1. 打开访达并转到下载文件夹
  2. 双击应用程序 Muse_Hub.dmg
  3. 在出现的对话框中，将 MuseHub 应用程序图标拖到你的应用程序文件夹中
  4. 双击应用程序文件夹图标以查看文件夹内部
  5. 双击 MuseHub 应用程序将其打开

在此过程中，你可能需要向 MuseHub 授予各种权限和文件夹访问权限。这些权限是确保 MuseHub 正确安装所必需的。

现在 MuseHub 已在你面前打开，是时候安装 MuseScore Studio 了：

  1. 单击左侧面板中的应用选项卡
  2. 找到 MuseScore Studio，并单击其下方的免费按钮开始下载和安装过程
  3. 应用下载完成后，单击 MuseScore Studio 图标下方的打开按钮。

现在开始创作音乐吧！

AppImage

安装

安装该程序最简单的方法是使用 AppImage：

  1. 前往 musescore.org 上的下载→软件页面
  2. 在 Linux→AppImage（推荐） 下，单击下载（64 位）链接
  3. 下载完成后，右键单击 AppImage 并选择属性
  4. 切换到权限选项卡
  5. 下一步根据你的文件管理器而有所不同： * 基于 Nautilus 的（Nemo、Files、Caja）：勾选“允许将文件作为程序执行”复选框。 * Dolphin：勾选“可执行”复选框。 * Thunar：勾选“允许此文件作为程序运行”复选框。 * PCManFM：在下拉列表中将“执行”选项改为“任何人”。
  6. 退出对话框。
  7. 在 AppImage 所在的目录内右键单击，并选择在终端中打开
  8. 在终端中键入 ./[文件名] install（开头的点和斜杠很重要！）

步骤 7 和 8 可确保 MuseScore 条目出现在系统菜单中，并链接到 AppImage 的新位置（/home/[用户名]/.local/bin）。正确的文件关联也会自动建立。

注意：除了上面的步骤 7 和 8，你当然也可以改用绝对文件路径来安装。即：

  1. 打开终端
  2. 键入 [文件路径] install

提示：如果你对 AppImage 执行复制，并在终端中按下 Ctrl+Shift+V，这将输入刚刚被“复制”的文件的绝对文件路径。

卸载

移除已安装的 AppImage 无需正式的卸载步骤。只需手动删除菜单项和任何快捷方式，然后删除应用本身及其链接（这些链接位于 \~/.local/bin 中）。
