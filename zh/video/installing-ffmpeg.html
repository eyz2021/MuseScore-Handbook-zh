安装 FFmpeg

FFmpeg 是一种在各种媒体格式之间进行转换的工具。如果您想在 MuseScore Studio 中导出视频，则必须通过下述方法之一安装 FFmpeg 的软件库。

其他安装 FFmpeg 的方法可能无法提供可在 MuseScore Studio 中使用的库。

Windows

下载 Buanzo 的 FFmpeg for MuseScore Studio，然后双击 MSI 进行安装。

安装 MSI 时，Microsoft Defender 可能会警告您它来自未知发布者。这只是意味着该安装程序未经签名。它并不一定意味着不安全。

这里有一个 VirusTotal 扫描，确认该文件不是恶意的。如果您不确定，可以自己将 MSI 上传到 VirusTotal。除了免费扫描之外，它还会显示一个 SHA-256 校验和，您可以将其与 Buanzo 网站上的校验和进行比较，以确认文件的完整性。

如果您信任该文件，可以单击更多信息和仍要运行。

您可以将 Buanzo 的 FFmpeg 安装到计算机上任意位置，MuseScore 4.7 将通过 Windows 注册表自动定位它。为此，您可能需要重新启动 MuseScore。

如果您想使用其他版本的 FFmpeg，则需要在 MuseScore 中通过 偏好设置 -> 视频 手动定位它。您需要浏览到包含 FFmpeg 的 DLL 的文件夹，例如 avformat.dll。在 Windows 上，这通常是 bin 文件夹（“binary”的缩写）。

macOS

下载 Buanzo 的 FFmpeg for MuseScore Studio，然后双击 PKG 进行安装。它会将 FFmpeg 安装到 MuseScore 应能自动找到的位置。为此，您可能需要重新启动 MuseScore。

Buanzo 的 PKG 已通过公证，这意味着它已经过 Apple 扫描和签名，以确认它不是恶意的。此外，这里还有一个 VirusTotal 扫描。如果您不确定，可以自己将 PKG 上传到 VirusTotal。

高级用户可以尝试改用 Homebrew 版本的 FFmpeg，它通过命令行安装。MuseScore 应能自动检测到 Homebrew 的 FFmpeg，但如果 Homebrew 将来更新了他们的版本，它可能不再适用于 MuseScore Studio。

如果您想使用任何其他版本的 FFmpeg，则需要在 MuseScore 中通过 偏好设置 -> 视频 手动定位它。您需要浏览到包含 FFmpeg 的 DYLIB 的文件夹，例如 avformat.dylib。在 macOS 上，这通常是 lib 文件夹（“library”的缩写）。

Linux

您可以从您的发行版安装 FFmpeg，MuseScore 4.7 应能自动找到它。

使用适用于您发行版软件包管理器的命令：

sudo apt install ffmpeg  # Debian、Ubuntu 及其衍生版本。
sudo pacman -Syu ffmpeg  # Arch、Manjaro 及其衍生版本。

在 Fedora、Redhat、CentOS 及其衍生版本上，您必须安装 RPM Fusion 软件仓库，然后运行：

sudo dnf install ffmpeg

如果您想使用任何其他版本的 FFmpeg，例如您自己编译的版本，则需要在 MuseScore 中通过 偏好设置 -> 视频 手动定位它。您需要浏览到包含 FFmpeg 的 SO（共享对象）文件的文件夹，例如 avformat.so。在 Linux 上，这通常是 lib 文件夹（“library”的缩写）。
