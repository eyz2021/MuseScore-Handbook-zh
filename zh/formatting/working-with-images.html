处理图像

图像可以通过附着到乐谱对象或框架上来插入到乐谱中。

支持的图像格式有 SVG（*.svg）、PNG（*.png）、JPEG（*.jpg 和 *.jpeg）。

  • SVG 推荐用于符号和 2D 图形，因为它使你能够在不失真的情况下调整图像大小。
  • 支持透明度和渐变。
  • 不支持高级 SVG 功能，如阴影、模糊、裁剪和遮罩。
  • PNG 也支持透明度，对于符号和 2D 图形比 JPEG 更可取。
  • 如果你无法获得图形的 SVG 版本，请使用 PNG。
  • 不要尝试将 PNG 转换为 SVG，因为这不会提供真正 SVG 图像的好处。
  • 考虑使用 TinyPNG 之类的免费工具来减小 PNG 文件大小而不降低质量。
  • JPEG 推荐用于照片和详细的 3D 纹理。
  • 只有在没有其他选择时才将其用于 2D 图形。
  • 不要尝试将 JPEG 转换为 SVG 或 PNG，因为这会增加文件大小而不会提供这些格式的好处。

此外，以 Bitmap（*.bmp）和 TIFF（*.tif 和 *.tiff）格式保存的图像可以使用，但并未得到完全支持。最好在导入 MuseScore Studio 之前将这些图像转换为 PNG 或 JPEG。

其他格式，如 GIF（*.gif）、WebP（*.webp）和 X PixMap（*.xpm）不受支持。这些图像必须在导入 MuseScore Studio 之前转换为 PNG 或 JPEG。

导入图像

向垂直或水平框架添加图像

此方法不适用于 Bitmap（*.bmp）或 TIFF（*.tif 和 *.tiff）图像。

  1. 右键单击框架
  2. 选择 添加→图像
  3. 从"插入图像"窗口中搜索并添加图像。

将图像附着到乐谱对象

对于与谱表关联的小图像（如音乐符号），或对于上述方法不支持的图像格式（例如 Bitmap、TIFF），请使用此方法。

  1. 在操作系统的文件管理器中找到图像文件（即在 MuseScore Studio 之外）。
  2. 缩小文件管理器窗口，使其与 MuseScore Studio 适配在同一屏幕上。
  3. 将图像文件从文件管理器拖到 MuseScore Studio。
  4. 继续拖动，直到光标定位在音符、休止符、小节或垂直或水平框架上。

将图像保存到面板

要将导入的图像保存到面板，请参阅从乐谱添加元素。

复制导入的图像

一旦图像被导入到乐谱中，就可以使用标准命令和步骤将其复制/剪切并粘贴到其他位置，如框架、音符或休止符（请参阅复制和粘贴）。

调整图像

更改图像高度/宽度

选择图像并使用以下任一方法：

  • 拖动任一图像调整手柄。
  • 在属性面板的图像部分编辑"图像高度/宽度"。

只要挂锁符号处于活动状态（在属性：图像中为蓝色），图像的宽高比（高度/宽度）就会一直保持。如果你想独立于另一侧调整一侧，请单击挂锁将其断开（变为灰色）。

缩放图像

要将图像缩放到包含框架的高度：

  1. 将框架调整到所需高度
  2. 在属性面板的图像部分勾选"缩放到框架大小"。

只要"缩放到框架大小"保持勾选，图像大小就会跟随框架高度。

调整图像位置

可以通过拖动来重新定位图像，或在属性面板的外观部分调整水平/垂直偏移量。Ctrl+R 将图像恢复到其默认位置。

图像属性

所选图像的图像属性可以在属性面板的图像部分调整。

  • 图像高度 / 挂锁 / 图像宽度：调整图像的尺寸。挂锁默认处于活动状态，确保保持所需的宽高比（高度/宽度）。
  • 缩放到框架大小：请参阅缩放图像（上文）。
  • 使用谱表空间单位：当勾选（默认设置）时，图像会自动按 格式→页面设置 中的缩放设置成比例缩放，并使用谱表空间单位 sp。如果取消勾选，图像使用 mm 且不会成比例缩放。请参阅页面排版概念。

\ _此符号高度为 4sp，因此它能完美地适应五线谱顶线和底线之间的空间。其"使用谱表空间单位"选项已勾选，因此它会成比例缩放。_
