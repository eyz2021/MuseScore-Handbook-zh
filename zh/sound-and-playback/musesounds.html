MuseSounds

MuseSounds 是一个由精密插件组成的音色库，可为 MuseScore Studio 提供逼真的播放效果。

安装

Muse Hub（Windows 和 macOS）

在 Windows 和 macOS 上，MuseSounds 通过 Muse Hub 实用程序安装，该实用程序也可用于安装 MuseScore Studio。如果你还没有 Muse Hub，可以免费从 musehub.com 下载。

安装后，Muse Hub 位于 Windows 系统托盘中（快捷键 Win+B 聚焦），或 macOS 菜单栏中（VoiceOver 运行时按 VO+M 两次聚焦）。

Muse Hub 打开后，在你希望加入音色库的任何音色下单击 获取，它就会立即开始下载和安装。

Muse Hub 还包含一系列效果器插件。请从 效果器 标签下载并安装这些插件。

插件完全下载后，将在你下次启动 MuseScore Studio 时出现在混音器中。

Muse Sounds Manager（仅限 Linux）

在 Linux 上，MuseSounds 通过 Muse Sounds Manager 安装，你可以从 musescore.org 下载适用于 64 位 Intel/AMD 架构的 DEB 或 RPM 包（目前不支持 ARM）。

Muse Sounds Manager 打开后，在你希望加入音色库的任何音色下单击 获取，它就会立即开始下载和安装。

插件完全下载后，将在你下次启动 MuseScore Studio 时出现在混音器中。

在 MuseScore Studio 中使用 MuseSounds

你下载的任何 MuseSounds 插件都会自动分配到乐谱中相应的乐器上。

你可以通过播放设置对话框，让 MuseScore Studio 始终使用可用的 MuseSounds 插件。

  1. 进入 视图 → 播放设置
  2. 在 配置文件 部分选择 MuseSounds
  3. 如果你希望未来所有乐谱也使用 MuseSounds，请保持 设为新乐谱的默认值 为勾选状态
  4. 单击 确定

MuseSounds 播放配置文件将确保所有 MuseSounds 插件被分配到乐谱中的每个可用乐器。你也可以通过混音器手动将 MuseSounds 插件分配到单个乐器。这对于有多个乐器的乐谱很有帮助，你可能希望将 Muse Sounds 插件与其他 VST 或 SoundFont 组合使用。

  1. 进入 视图 → 混音器 以显示 混音器（快捷键：F10）
  2. 悬停在 音色 旁边的插件插槽上
  3. 单击出现的下拉按钮
  4. 导航到 MuseSounds 并从所需的音色库中选择一个音色

任何 MuseSounds 不支持的乐器将保持默认分配给 MS Basic。
