自定义打击乐面板

你可以以各种方式自定义打击乐面板，以最适合你的个人偏好和工作流程需求。

查看鼓垫名称或记谱预览

默认情况下，打击乐面板会显示所选乐器中每个子乐器和变体的名称。

要改为查看每个鼓垫的记谱预览：

  1. 单击打击乐面板标题中的 布局。
  2. 选择 记谱预览。

将鼠标指针悬停在鼓垫上，可查看显示分配给该鼓垫的乐器或变体名称的工具提示。

要切换回查看鼓垫名称：

  1. 单击打击乐面板标题中的 布局。
  2. 选择 鼓垫名称。

你选择的鼓垫名称或记谱预览会保存到乐谱中，因此不会影响其他乐谱中的面板布局。此外，它适用于乐谱中的所有无音高打击乐器——而不只是你正在处理的那一个。

将鼓垫移动到不同位置

你可以更改每个鼓垫的位置，以最适合你的乐器设置或首选布局。

要更改鼓垫的位置：

  1. 单击打击乐面板标题中的 布局。
  2. 选择 编辑布局。每个鼓垫位置周围会出现一个轮廓，表示你现在可以编辑鼓垫布局。
  3. 单击并将鼓垫拖动到另一个位置。
  4. 松开鼠标，将鼓垫放到新位置。
  5. 单击打击乐面板标题中的 完成编辑，继续书写音乐。

你也可以仅使用计算机键盘将鼓垫移动到不同位置。

  1. 使用 Tab 聚焦某个鼓垫
  2. 使用方向键将焦点移动到所需鼓垫
  3. 按 Space 或 Enter 选中你想移动的鼓垫
  4. 使用方向键将选中的鼓垫移动到不同的插槽位置
  5. 按 Space 或 Enter 将鼓垫放到新位置

删除鼓垫

你可以删除不需要的鼓垫以节省空间。

要删除鼓垫：

  1. 单击鼓垫底部的灰色面板（或按 Tab 然后按 Enter 导航到它）。
  2. 选择 删除。

删除鼓垫后，其原位置会留下一个空位。这可以用作间隔，也可以作为不同鼓垫的位置（见将鼓垫移动到不同位置）。

添加和移除行

更改打击乐面板的行数可以让你更灵活地以最适合你的项目和工作流程需求的方式排列鼓垫。

要在打击乐面板中添加行：

  1. 单击打击乐面板标题中的 布局。
  2. 选择 编辑布局。
  3. 单击 添加行。

鼓垫可以移动到空位（见将鼓垫移动到不同位置）。

手动添加的行可以通过单击行左侧的垃圾桶按钮删除。

更改列数

  1. 单击打击乐面板标题中的 布局。
  2. 悬停在 8 列 上（如果你已自定义过，这可能显示其他数字）。
  3. 选择新的列数（4、6、8、12、16、20 或 24）。

保存并重用自定义鼓垫布局

一旦你为乐谱中的特定乐器自定义了打击乐面板，就可以保存所有布局更改和键盘快捷键，以便在此乐谱或其他乐谱中使用相同乐器和音色时再次使用。

保存自定义布局：

  1. 对鼓垫布局进行任何所需的自定义。
  2. 单击打击乐面板标题中的 自定义套件。
  3. 在对话框中单击 另存为... 并将其保存到你的计算机。这会创建一个 .drm 文件，你可以在任何乐谱中加载它。

将保存的布局加载到不同的乐器：

  1. 在属于你想加载已保存打击乐面板布局的乐器的谱表上选中任何内容。
  2. 单击打击乐面板标题中的 自定义套件。
  3. 单击 加载...，然后选择你上面创建的 .drm 文件。
  4. 单击 应用 或 OK 应用更改。

取消停靠并调整面板大小

与所有面板一样，打击乐面板可以取消停靠并调整大小，以为你的项目和设置创建最佳工作区。

了解有关停靠和取消停靠面板以及将你的首选应用布局保存为工作区的更多信息。

选择何时使用新的打击乐面板

根据你的屏幕大小以及所用乐器中的鼓垫数量，你可以选择使用旧版打击乐面板而不是新版。旧版面板将继续可用，直到添加更多功能以更好地为大型乐器优化新版面板。

要使用旧版打击乐面板：

  1. 打开偏好设置。
  2. 在导航面板中单击 打击乐。
  3. 打开 使用旧版打击乐面板。

请注意，分配给打击乐乐器的任何自定义键盘快捷键都将同时适用于新版和旧版面板。
