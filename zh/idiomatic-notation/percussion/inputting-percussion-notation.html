输入打击乐记谱

本节介绍无音高打击乐器的音符输入。有关有音高打击乐器，请参阅输入音符和休止符。

概述

在 MuseScore Studio 中，每个无音高打击乐器（包括鼓组和混合打击乐等组合乐器）都预先配置好，可实现无缝记谱和播放。

这意味着当你添加乐器时——无论是单个牛铃还是完整的鼓组——套件中每个子乐器（低音鼓、小军鼓、钹等）的记谱，以及任何技巧和变体（敲击、鼓边敲击、鼓边敲击等）都会自动配置。MuseScore Studio 会处理套件的谱表线数量，以及谱表上所有符头的形状和位置。此外，在播放中，MS Basic 和 MuseSounds 音色库会自动分配正确的音色。

如果你有独特的记谱需求，当然也有选项来自定义每个乐器的映射（见打击乐套件自定义）。

将打击乐器添加到你的乐谱

你可以像添加任何其他乐器一样添加打击乐器（见设置你的乐谱和排版面板）。

每个无音高打击乐器都附带一组预先配置的子乐器，以及由混音器中选择的音色库决定的变体和技巧。

除了单个管弦打击乐器和行进鼓队外，MuseScore Studio 还附带几个组合套件，它们将许多常见子乐器组合到一个谱表上。这些包括：

  • 鼓组（常用、最小、大型）
  • 混合打击乐
  • 通用 MIDI 打击乐

可以为任何现有无音高乐器的谱表自定义独特的子乐器组合，尽管播放支持可能并不总是可用。要了解更多，请参阅打击乐套件自定义。

在打击乐谱表上输入音符和休止符

在打击乐谱表上输入记谱有几种方法。我们将逐一介绍。它们是：

  • 使用打击乐输入面板
  • 用鼠标直接在谱表上输入
  • 键盘快捷键
  • 通过 MIDI 键盘输入
  • 使用虚拟钢琴输入

使用打击乐输入面板

要打开打击乐输入面板：

  • 选中无音高打击乐器的谱表，或
  • 在无音高打击乐谱表上选中音符或休止符

打击乐面板 会出现在应用窗口底部。它显示所选谱表上可用的所有子乐器和变体，由混音器中为该乐器分配的音色库决定：

要使用打击乐输入面板输入记谱，单击任意鼓垫即可。记谱会输入到音符输入光标的位置，无论所选子乐器或变体被分配到哪个声部。

https://drive.google.com/file/d/1nQBLrG9wW06R7FEkxyWrxLFgmXnlQWNe/view?usp=sharing

默认会启用 写入模式。这意味着单击鼓垫将直接在谱表上输入记谱。

要不输入记谱而听到分配给鼓垫的乐器音色：

  1. 单击打击乐面板标题中的 预览 按钮
  2. 单击 鼓垫 以听到其声音
  3. 再次单击 写入 按钮以继续记谱

详见自定义打击乐面板。

用鼠标直接在谱表上输入

要用鼠标直接在谱表上输入打击乐记谱：

  1. 选中你想输入记谱的谱表
  2. 进入音符输入模式
  3. 将鼠标指针悬停在谱表上，可看到分配给该谱表位置的乐器或变体的预览音符
  4. （可选） 悬停时按住 Shift，可看到标记每个谱表位置乐器的弹出框。当弹出框中出现左右箭头时，单击它们可在同一谱表间或谱线上的可用变体之间滚动。
  5. 左键单击符头以输入音符

预览音符显示鼠标指针悬停所在谱表位置可用的任何乐器或变体。当你移动鼠标时，预览音符会改变以显示每个新位置可用的内容。

键盘快捷键

你可以为打击乐面板中的每个鼓垫分配一个键盘快捷键。

默认情况下，第一行鼓垫将采用 A、B、C、D、E、F、G、H 键。任何键都可以分配给鼓垫，不过如果你选择的键与其他快捷键命令冲突，系统会提示你。

要为鼓垫分配键盘快捷键：

  1. 单击鼓垫底部灰色的 选项 部分（或使用 Tab 键导航到它）
  2. 选择 定义键盘快捷键

使用 MIDI 控制器

要使用 MIDI 键盘将音符添加到无音高打击乐谱表：

  1. 选中音符、休止符或小节
  2. 选择音符时值
  3. 按 MIDI 键盘上的某个键以输入音符
  4. （可选） 按 0 输入所选时值的休止符

记谱将以偏好设置中设为默认的任何音符输入模式输入到谱表上。有关使用不同音符输入模式的更多信息，请参阅输入音符和休止符。

打击乐面板上的每个鼓垫都显示分配给每个可用子乐器或变体的 MIDI 键。请注意，这些会根据混音器中分配给该乐器的音色库而变化。

使用屏幕钢琴键盘

要使用 MuseScore Studio 的屏幕 钢琴键盘 将音符添加到无音高打击乐谱表：

  1. 通过前往 视图 > 钢琴键盘 打开 钢琴键盘（或使用快捷键 P）
  2. 选中小节、音符或休止符
  3. 选择音符时值
  4. 用鼠标单击屏幕钢琴键盘上的一个键
  5. （可选） 要向现有音符添加另一个音符，按住 Shift 并单击不同的键
  6. （可选） 按 0 输入所选时值的休止符

应用其他技巧和变体

许多音色库带有额外的技巧和变体，可以扩展你乐器的演奏表现。例如，小军鼓可以设置为开或关，或者可以使用不同的鼓棒，包括鼓棒、鼓刷和细鼓棒。

这些使用声音标记添加。请注意，此功能目前仅适用于部分 MuseSounds 音色库。选项将因所选音色库而异。
