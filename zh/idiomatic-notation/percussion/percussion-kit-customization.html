打击乐套件自定义

概述

你可以为无音高打击乐器中的每个子乐器和变体自定义名称、符头样式、谱表位置、符干方向、键盘快捷键和默认声部分配。

要访问这些选项，请从打击乐面板标题中单击 自定义套件。

自定义打击乐记谱

使用 自定义套件 对话框中的选项，你可以：

  • 重命名子乐器和变体
  • 自定义符头
  • 分配默认声部
  • 更改谱表位置
  • 分配键盘快捷键
  • 选择默认符干方向

在左侧面板中，你可以通过以下方式对子乐器和变体的列表进行排序：

  • 单击 编号 列标题按 MIDI 编号排序
  • 单击 音符 列标题按音高排序
  • 单击 快捷键 列标题按键盘快捷键排序
  • 单击 名称 列标题按名称排序

按 MIDI 编号 排序可以让你看到子乐器和变体的名称，其顺序与它们在打击乐面板中作为鼓垫出现的顺序相同。

在此对话框中进行的任何自定义都会立即显示在预览面板中。更改也会自动显示在乐谱中，但只有在你单击 OK 时才会提交。这些更改是可撤销的。

重命名子乐器和变体

要重命名子乐器或变体：

  1. 从左侧面板中选择一个乐器
  2. 在 名称 旁边的字段中输入你想要的标签。

当你单击 应用 或 OK 时，打击乐面板中相应的鼓垫标签会更新。

自定义符头

要自定义分配给子乐器或变体的符头：

  1. 从左侧面板中选择一个乐器
  2. 单击 符头组 旁边的下拉菜单
  3. 从下拉菜单中的大量符头中选择

每个符头组最多有四种可能的样式变体，用于不同的时值（四分音符、二分音符、全音符、倍全音符）。这些是预定义的，但如果你有特定要求，可以编辑。

要编辑符头组中单个时值的符头：

  1. 勾选 编辑符头 复选框
  2. 在相应的下拉菜单中为每个时值选择你所需的符头

分配默认声部

要更改子乐器或变体分配到的默认声部：

  1. 从左侧面板中选择一个乐器
  2. 在 默认声部 旁边的下拉菜单中选择声部 1、2、3 或 4

更改声部分配会影响所选子乐器或变体的所有未来记谱，但不会改变现有记谱。

更改谱表位置

要更改子乐器或变体所在的谱线或谱间位置：

  1. 从左侧面板中选择一个乐器
  2. 通过单击 谱线 旁边微调框中的箭头，将其符头向上或向下移动

分配键盘快捷键

要为子乐器或变体分配键盘快捷键：

  1. 从左侧面板中选择一个乐器
  2. 单击 快捷键 旁边的按钮
  3. 输入一个键以设置快捷键
  4. 单击 保存 以确认你的选择

如果你选择的快捷键与其他分配冲突，会出现一条消息。此时单击 保存 会触发提示，要求你确认选择。

在某些情况下，分配一个已在使用的快捷键可能是可以的。MuseScore Studio 可以识别快捷键是用于打击乐记谱输入，还是适用于打击乐系统之外的某些内容。

如果快捷键的更改导致现有功能不再可能，请选择其他快捷键，或在 定义打击乐键盘快捷键 对话框中单击 清除 移除该快捷键。

选择默认符干方向

要更改子乐器或变体的默认符干方向：

  1. 从左侧面板中选择一个乐器
  2. 在 符干方向 旁边的下拉菜单中选择 向上、向下 或 自动

更改符干方向会影响所选子乐器或变体的所有未来记谱，但不会改变现有记谱。

保存更改并在其他乐谱中使用

完成自定义后，按 OK 提交更改。这些更改会保存到你的乐谱文件中。

也可以保存所有自定义以及打击乐面板中的鼓垫布局，以便在其他乐谱中使用。

要将打击乐套件保存以供其他乐谱使用：

  1. 通过单击对话框左下角的 另存为... 将你的设置保存为鼓组文件（.drm）
  2. 在计算机上选择文件位置。默认情况下，文件将保存在 MuseScore Studio 的 样式 文件夹中
  3. 单击 保存

将鼓组文件加载到另一个乐谱时，请记住，虽然鼓组文件在技术上可以加载到任何无音高打击乐器上，但只有在混音器中选择了正确的音色库时，播放才会正确工作。

设置乐谱时，最安全的做法是添加一个与你之前自定义的乐器相匹配的乐器。

要将打击乐套件加载到另一个乐谱中：

  1. 创建或打开另一个包含无音高打击乐器的乐谱
  2. 选中该乐器的谱表
  3. 单击打击乐面板标题中的 编辑套件
  4. 在出现的 自定义套件 对话框中，单击左下角的 加载... 按钮
  5. 找到你保存的鼓组（.drm）文件
  6. 单击 打开

你的自定义（包括对打击乐面板布局所做的任何更改）现在就可以在你的新乐谱中使用了。
