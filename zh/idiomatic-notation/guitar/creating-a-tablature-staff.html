创建吉他谱（TAB）谱表

概述

带品弦乐器的音乐通常使用 吉他谱（TAB，常缩写为 tab）记谱；它直观地表示琴弦和品位数字。吉他谱常与传统的五线谱记谱结合使用。

吉他谱谱表的类型

软件提供了多种常见乐器的吉他谱模板。如果这不完全符合你的需求，你可以轻松更改模板（见更改吉他谱谱表类型），和/或自定义谱表（见吉他谱：自定义）。

将吉他谱谱表添加到你的乐谱

有三种方式：

  • 作为新乐谱的一部分创建吉他谱。
  • 将吉他谱添加到现有乐谱。
  • 将现有谱表从标准谱表更改为吉他谱。

使用新建乐谱对话框添加吉他谱

要作为新乐谱的一部分创建吉他谱：

  1. 打开新建乐谱对话框。
  2. 从 选择乐器 或 从模板创建 选项卡中选择所需的吉他谱。
  3. 完成新建乐谱对话框的其余部分。

使用乐器对话框添加吉他谱

要在现有乐谱中创建吉他谱谱表：

  1. 在 排版 面板中，单击 Add（添加）按钮；或按快捷键 I。这会打开 添加或移除乐器 对话框。
  2. 单击 弦乐 – 拨弦 族，并从 乐器 列中选择所需的吉他谱。
  3. 按 OK。

将现有谱表从标准谱表更改为吉他谱

  1. 确保标准谱表包含拨弦乐器；
  2. 使用更改吉他谱谱表类型中所述的其中一种方法。

创建配对的标准谱表与吉他谱谱表

吉他（及其他拨弦乐器）的音乐通常使用配对的标准谱表和吉他谱谱表来记谱。在 MuseScore 中，谱表可以是关联的或非关联的。

  • 关联：你对其中一个谱表记谱所做的任何更改都会自动更新另一个谱表。
  • 非关联：每个谱表独立编辑。要更新另一个谱表，请复制并粘贴相关音乐记谱。

注意：在这两种情况下，谱表/吉他谱对共享同一个乐器。

使用新建乐谱向导创建配对的标准/吉他谱谱表

创建新乐谱时有两种方法（A 或 B）：

A. 仅适用于关联谱表：

  1. 打开新建乐谱向导。
  2. 在“从模板创建”选项卡中，单击“Solo”类别并选择“Guitar + Tablature”。
  3. 完成新建乐谱向导的其余部分。
  4. 如有需要，在谱表/分谱属性中更改乐器类型。
  5. 如有需要，更改吉他谱类型（见更改吉他谱谱表类型）。

B. 适用于关联或非关联谱表：

  1. 打开新建乐谱向导。
  2. 在“选择乐器”选项卡中，单击“弦乐 – 拨弦”族，并从“乐器”列中选择一个谱表选项。
  3. 完成向导的其余部分。
  4. 使用乐器面板添加所需谱表。

使用乐器对话框创建配对的标准/吉他谱谱表

当你想添加到现有乐谱时使用此方法：

  1. 打开 添加或移除乐器 对话框：按 I；或者，单击 乐器 侧栏中的 Add（添加）按钮
  2. 单击 弦乐 – 拨弦 族，并从 乐器 列中选择所需谱表。
  3. 按 OK。
  4. 从排版面板添加所需吉他谱。

注意：如果你的乐谱中已有标准/吉他谱对中的一个谱表，你可以直接从 乐器 面板添加缺失的谱表。见添加与配置谱表。
