自定义吉他谱谱表

更改调弦

  1. 右键单击谱表并选择 谱表/分谱属性…
  2. 按下对话框底部的 Edit String Data…（编辑琴弦数据…）按钮。这会打开 琴弦数据 对话框：\
  1. 在 琴弦调弦 下，单击一个琴弦音高并选择 Edit String…（编辑琴弦…）；或者，直接双击该琴弦音高。
  2. 在音符选择框中选择新音高并单击 OK。或者，直接双击新音高。
  3. 单击 OK 关闭“琴弦数据”对话框。
  4. 单击 OK 关闭谱表/分谱属性对话框。

注意：(1) 如果在已包含一些音符的吉他谱谱表上更改调弦，品位标记会自动调整（如果可能的话）；(2) 对特定乐器的任何调弦更改仅适用于当前乐谱，不会更改任何程序默认设置。

添加或移除琴弦

添加琴弦

  1. 右键单击谱表并选择 谱表/分谱属性…
  2. 单击 Edit String Data…
  3. 单击一个琴弦音高并选择 New String…（新建琴弦…）
  4. 选择新音高并按 OK；或者，直接双击新音高。

新琴弦会插入到所选琴弦的下方。你还需要在谱表/分谱属性→高级样式属性中调整线的数量。

删除琴弦

  1. 右键单击谱表，选择 谱表/分谱属性…
  2. 单击 Edit String Data…
  3. 单击一个琴弦音高并按 Delete String（删除琴弦）。

注意：删除吉他谱琴弦后，你还需要在谱表/分谱属性→高级样式属性中调整线的数量。

将未按品琴弦标记为“空弦”

对于诸如巴洛克鲁特琴之类的乐器，此功能用于将低音弦组标记为不按品——即始终像竖琴弦一样空弦演奏。这意味着只能显示表示第零品的品位标记。

要将低音弦组标记为不按品：

  1. 右键单击谱表，并选择 谱表/分谱属性...
  2. 单击 Edit String Data…
  3. 勾选 开放（Open） 列中所需的复选框。

另见古乐器吉他谱记谱。

更改乐器品数

此属性定义了可在吉他谱谱表上输入的最大品位数字。

  1. 右键单击谱表，并选择 谱表/分谱属性…
  2. 单击 Edit String Data…
  3. 使用“品数”微调框选择或输入新数字。

更改吉他谱谱表类型

MuseScore 提供了一系列常见的吉他谱类型。如果你想更改吉他谱类型，有两种选择：

从排版面板更改谱表类型

  1. 确保 排版 面板可见（切换 F7）。
  1. 单击乐器名称旁的箭头以显示各谱表。
  2. 单击所需谱表旁的编辑齿轮，并从“谱表类型”下拉菜单中选择一个选项。
  3. 要关闭，按 Esc，或单击对话框外部。

从谱表/分谱属性更改谱表类型

  1. 右键单击谱表的空白区域并选择 谱表/分谱属性…。
  2. 单击 高级样式属性，从“模板”中选择所需选项，然后按 < 重置为模板。如有必要，可以使用“品位标记”和“音符时值”选项卡微调显示。
  3. 单击两次 OK 退出。

注意：有关自定义选项的详细信息，请参阅自定义吉他谱外观（下文）。

你会在吉他谱类型名称中找到“简单（simple）”、“常用（common）”和“完整（full）”这些术语：

  • 简单：仅显示品位标记。
  • 常用：显示品位标记、休止符、符干和符杠。
  • 完整：显示品位标记、休止符、符干和符杠，以及二分音符符干。

自定义吉他谱外观

吉他谱谱表属性

  1. 右键单击谱表并选择 谱表/分谱属性…
  2. 单击 高级样式属性…。

这会让你访问全面的吉他谱自定义选项。见谱表属性：吉他谱选项。

吉他谱谱表样式

全局设置在 格式→样式→吉他谱样式 中设置。\
