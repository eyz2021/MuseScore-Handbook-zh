吉他推弦与下压

本页介绍专门用于吉他演奏的音高推弦和下压。对于其他类型的推弦，见铜管或木管乐器推弦。

关于推弦与下压

推弦线和下压线可用于表示向下或向上的音高推弦。

推弦是通过用手指按住指板上的琴弦，将琴弦向上或向下拉动而产生的。

下压是通过按压或拉起连接在吉他琴桥上的摇把/颤音杆而产生的。

推弦会改变单个音符及和弦的音高，而下压会均匀地改变所有琴弦的音高。

以下类型的推弦和下压可以添加到你的乐谱中：

推弦 下压
标准推弦 标准下压
预推弦 预下压
倚音推弦 下潜
轻微推弦 起音

所有这些元素都可以在 吉他面板 中找到。

它们在 MuseScore Studio 中的工作原理

在大多数情况下，MuseScore 中的推弦和下压连接两个音符：“起始音符”和“到达音符”。

推弦和下压是上下文相关的，意味着如果到达音符高于起始音符，就会创建向上的推弦/下压。相反，如果到达音符低于起始音符，就会绘制释放或向下的下压。

每当推弦/下压添加到吉他谱谱表时，起始音符和到达音符都会以品位位置输入。然而，到达音符默认隐藏。这让你可以仅使用吉他谱谱表创建多个推弦或下压的序列，包括推弦-释放-推弦组合，而无需在标准谱表中输入音符。如果你主要在标准谱表中工作，你可能会发现通过属性面板中的 不可见 设置隐藏这些品位位置更方便。

在所有情况下，推弦/下压幅度，即起始音符与到达音符之间的音程距离，由标准谱表上的记谱音高反映。这让你可以看到旋律线的形状，包括推弦产生的音高。它还可以让旋律线的节奏（包括任何推弦和下压的节拍时值）清晰地传达给演奏者。

在吉他谱谱表上，推弦/下压幅度由数字指示器给出：“1”表示全音，“1/2”表示半音，“1/4”表示四分之一音，等等。

添加推弦和下压

你可以通过以下任何方式将所有类型的推弦和下压应用到你的乐谱：

  • 选中一个或多个音符，并单击 吉他 面板中所需的推弦/下压符号
  • 将所需的推弦/下压符号从 吉他 面板拖到一个音符或和弦上
  • 选中一个或多个音符，并输入所需的键盘快捷键（详见下文）

推弦和下压可以添加到单个音符和和弦上。在添加所需的推弦或下压元素之前，只需选中所有你想应用音高推弦的音符即可。在吉他谱谱表上，相同音程值的和弦音符之间的推弦线会自动合并为一个音程数字，而对于连接多个和弦的下压线，只会绘制一条线。

### 标准推弦 Windows Alt+B | macOS Option+B
标准推弦连接两个音符：“起始音符”和“到达音符”。标准推弦主要用于希望明确指定推弦模式节奏的情况。 当推弦添加到音符时，它会自动绘制到乐谱中的下一个音符（到达音符）。如果起始音符之后是休止符，MuseScore 会替换该休止符，以便推弦有一个到达音符可以连接。 ### 倚音推弦 Windows Ctrl+Alt+B | macOS Cmd+Option+B
倚音推弦可用于表示没有固定节奏时值的推弦；它们通常在拍子之前很快地弹奏。 当你将倚音推弦应用到音符时，它会自动输入为比其所引导的音符低一个自然音级的音。 ### 预推弦 无默认键盘快捷键：在[偏好设置](/customization/preferences.md)中设置你自己的快捷键
预推弦表示在拨弦之前已经推好的琴弦。在标准谱表上，它表示为无符干、带括号的倚音。在吉他谱谱表上，它以直线箭头而非曲线箭头表示。 ### 轻微推弦 无默认键盘快捷键：在[偏好设置](/customization/preferences.md)中设置你自己的快捷键
轻微推弦是 MuseScore 中唯一不连接到到达音符的推弦类型。 它们始终设置为预定义的 ¼ 音幅度，并且始终从起始音符向上推。
### 标准下压 无默认键盘快捷键：在[偏好设置](/customization/preferences.md)中设置你自己的快捷键。
标准下压连接两个音符：“起始音符”和“到达音符”。标准下压主要用于希望明确指定下压模式节奏的情况。 当下压添加到音符时，它会自动绘制到乐谱中的下一个音符（到达音符）。如果起始音符之后是休止符，MuseScore 会替换该休止符，以便下压有一个到达音符可以连接。 ### w/bar 文字线 “w/bar”文字线是一个单独的元素，可以从 **吉他** 面板按需添加。自定义它的选项可在[**样式**](#customizing-the-style-of-bends-and-dives)中找到。 ### 预下压 无默认键盘快捷键：在[偏好设置](/customization/preferences.md)中设置你自己的快捷键。
预下压表示在拨弦之前已经使用摇把/颤音杆改变了琴弦的音高。在标准谱表上，它表示为无符干、带括号的倚音。在吉他谱谱表上，它用虚线垂直线而非不间断的对角线表示。 ### 下潜
下潜表示在所附着音符的时值内的一次音高推弦序列。 音符弹响后，下潜可以表示向上或向下的音高推弦，达到文字标签中指定的音程值，然后摇把/颤音杆回到起始位置。 下潜的方向和音程值可以在 **属性** 面板中指定。 在 **属性** 中，你还可以在下潜的末尾附加一条 **颤音线**： 1. 选中乐谱中的下潜 2. 前往 **属性** 3. 在 **颤音线** 下，选择 **普通** 或 **宽** 线。 颤音线会显示为连接到所选的下潜。它的长度可以通过移动其拖动手柄来调整（见[使用线条](/basics/adjusting-elements-directly.md#working-with-lines)）。 ### 起音
起音由指向符头的小刻度线表示。它们的弹奏方式是在拨弦前不久将摇把/颤音杆稍微向下压。当琴弦被拨响时，摇把/颤音杆迅速回到静止位置。

保持

每当包含推弦或下压的音符或和弦随后通过延音线连接到一个或多个音符时，保持线就会自动绘制。

保持由虚线水平线表示。它只显示在吉他谱谱表中。

此外，你可以在有意义的地方手动显示或隐藏保持线。

  1. 选中乐谱中的推弦或下压
  2. 打开属性面板
  3. 在 保持线 下，选择 显示 或 隐藏，分别强制绘制或隐藏保持线

修改推弦和下压

推弦的音程幅度和播放速度都可以在 MuseScore 中调整，方法是在标准谱表上修改推弦音符的音高，或在 属性 面板中调整推弦/下压曲线。

在标准谱表上修改推弦和下压

要在标准谱表上更改推弦或下压的推弦幅度，只需升高或降低乐谱中起始音符或到达音符的音高。任何关联吉他谱谱表中的分数指示器都会自动调整。

轻微推弦、下潜和起音只能通过 属性 面板调整其播放时值和音程值。

在属性面板中修改推弦和下压

音高推弦幅度及其播放速度都可以通过 属性 面板调整。

要调整推弦幅度：

  1. 使用上文概述的任何方法将推弦应用到你的乐谱
  2. 选中推弦
  3. 打开属性面板
  4. 在 自定义推弦/下压 图中，单击并向上或向下拖动曲线的端点
https://drive.google.com/file/d/1DvZk9b5PoZCnDIcsMAKUZvkTevToO9U4/view?usp=sharing

推弦/下压曲线也可以仅使用计算机键盘修改，无需使用鼠标。

  1. 导航到乐谱中的推弦或下压（见导航乐谱）
  2. 按 esc
  3. 使用 tab 导航到 属性 面板
  4. 按 tab 直到到达 推弦/下压 部分
  5. 按 down 方向键直到到达自定义推弦/下压部分
  6. 按 spacebar（空格键）选中曲线的起始位置点
  7. 按住 alt（macOS 上为 Option），同时使用 left 和 right 方向键在曲线上的点之间切换
  8. 使用 up 和 down 方向键修改所选点的音高

推弦/下压曲线最左边的点对应起始音符。最右边的点对应到达音符。

向上拖动曲线最右端（端点）会以 ¼ 音步进升高到达音符。同样，向下拖动端点会降低到达音符的音高。吉他谱谱表中的分数指示器以及标准谱表中的记谱音高都会相应更新。

要调整推弦/下压的播放速度：

  1. 选中乐谱中的推弦/下压
  2. 打开属性面板
  3. 在 自定义推弦/下压 图中，单击并向左或向右拖动曲线的起点和终点

水平拖动曲线点只会更改其播放速度，包括起始音符和到达音符保持的时长（以水平线表示）。它不会影响乐谱中的节奏记谱。

特殊情况

显示松弛的琴弦

松弛 线表示颤音/摇把被压到琴弦松弛、不再产生可辨音高的程度。

要创建 松弛 线：

  1. 选中乐谱中的标准下压
  2. 前往 属性
  3. 单击并拖动 自定义下压 曲线的端点一直到底部
https://drive.google.com/file/d/1HZEg4Ns65cKXTPnsnuLN7RdaT7a7lWkY/view?usp=sharing

创建同度推弦

要创建同度推弦：

  1. 创建一个包含两个同度音符的和弦（使用 Windows 上的 alt+1，或 macOS 上的 option+1，向现有音符添加一个同度音程）
  2. 选中你想应用推弦的音符
  3. 添加所需的推弦（见上文步骤）

对于同度推弦，在吉他谱谱表中应用推弦会很有帮助，因为在吉他谱中更容易看出具体推的是哪根琴弦。

自定义推弦与下压的样式

要自定义整个乐谱中推弦和下压的外观：

  1. 前往菜单栏中的 格式
  2. 选择 样式...
  3. 在出现的对话框中，从左侧类别列表中选择 推弦与下压

以下选项可用：

**线条粗细**：标准谱表和吉他谱谱表上所有推弦线的粗细 **箭头宽度** 和 **箭头高度**：吉他谱谱表中推弦曲线上箭头头的宽度和高度 **全音推弦的标签**：选择显示“1”或“full”来表示吉他谱谱表中的全音推弦
**线条粗细**：标准谱表和吉他谱谱表上所有下压线的粗细 **显示下压线的选项：** * **在谱表上**：所有下压线将直接绘制在吉他谱谱表线上 * **在谱表上方**：所有下压线将绘制在吉他谱谱表上方
也可以通过 **属性** 面板将选中的单个下压线移动到 **谱表上方**。
各种 **摇把线** 选项，用于修改默认文字及其样式（默认使用 'w/bar'），以及自定义线元素本身的选项（包括其样式、粗细以及虚线和间隙值）。
**使用提示大小的品位数字**：勾选此复选框可使倚音的所有品位位置使用提示大小（默认情况下，倚音推弦的品位位置数字与其他类型推弦的品位位置数字大小相同）。 你可以使用单选按钮切换，将预推弦和预下压绘制的垂直线对齐到 **主音符** 或 **倚音音符**。 上述选项仅适用于吉他谱谱表。 分数音程的 **音程标签**（'1/2'、'1/4' 等）可以使用本页底部的切换按钮设置为对角样式或水平基线样式。文字样式本身可以在 **文字样式** 页面中修改。
