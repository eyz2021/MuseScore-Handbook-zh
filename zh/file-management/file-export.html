导出文件

概述

本章介绍将 MuseScore 乐谱保存为原生格式（*.mscz 和 *.mscx）以外的其他格式，例如 MusicXML、MIDI、MEI、MP3、PDF、PNG 等。

导出乐谱

要导出乐谱：

  1. 选择 文件→导出
  2. 从下拉列表中选择一种 格式
  3. 通过勾选/取消勾选对话框左侧的相应复选框，选择 要导出的分谱
  4. 如果想将所有分谱合并到一个文件中，请单击标题为 所有分谱合并到一个文件 的单选按钮
  5. 单击 导出...

文件格式

图形格式

PDF

便携式文档格式（PDF）是一种适用于文本、图片、乐谱等的通用格式。当你想生成供其他音乐家阅读的乐谱时，请使用此格式。

几乎每台计算机都会装有专用的 PDF 阅读器；如果没有，也可以使用 Firefox 等网页浏览器打开 PDF。如果需要，PDF 乐谱也可以打印成纸质副本。

SVG

与 PDF 类似，可缩放矢量图形（SVG）可以在不损失质量的情况下放大图像。当你想把乐谱片段嵌入到其他文档或网页中时，请使用 SVG。

所有现代网页浏览器都支持 SVG。但是，许多网站和应用不支持它，因此如果你在某个地方使用 SVG 不成功，可以改用 PDF 或 PNG。

PNG

便携式网络图形（PNG）是一种压缩图形格式，适用于编辑或嵌入各种文档。但是，PNG 在放大图像时会变得像素化，因此如果你的软件支持，请考虑改用 PDF 或 SVG。

音频格式

AAC

AAC（高级音频编码）使用有损压缩，旨在成为 MP3 格式的继任者。在相同比特率下，它通常能获得比 MP3 更高的音质。与 MP3 一样，此格式用于聆听目的（不用于编辑）。

MP3

MP3 是一种被普遍支持的有损压缩格式。使用此格式或 AAC 与他人分享音频（用于聆听目的，不用于编辑）。

OGG

OGG 文件通常包含有损的 Vorbis 压缩音频，在相同文件大小下比 MP3 提供更高的音质。如果你的设备支持，可以将此格式用于个人聆听。

大多数 Android 设备支持 OGG 音频，但 Windows、macOS 和 iOS 设备需要第三方软件才能读取这些文件。你可能会发现 AAC 或 MP3 更容易使用。

FLAC

FLAC 是一种无损压缩格式，能完整保留音频质量，但生成的文件比有损压缩格式更大。当需要把音频发送给他人编辑时使用 FLAC，但前提是你无法将实际的 MuseScore 文件发送给他们（例如，因为他们没有安装必要的乐器音色或音频插件，无法按你的意图发声）。

WAV

WAV 是一种未压缩格式。它提供完整的音频质量，但文件非常大。当你计划在另一个程序（如 Audacity）中自行编辑音频时，请使用此格式。

其他音频格式

如果你需要上述未提及的音频格式（例如 Opus），则需要使用外部音频转换工具。Audacity 是一个可以用于此目的的免费程序。它由 Muse Group 开发，该公司也开发 MuseScore。

只需将你的乐谱从 MuseScore 导出为 WAV 文件，然后在 Audacity 或你选择的其他音频程序中打开该文件进行转换。使用 WAV 作为过渡格式可确保转换后的最高音质，并避免在 MuseScore 中压缩文件后又在其他程序中立即解压而浪费时间。

或者，你也可以使用网站进行转换。在这种情况下，最好使用 FLAC 作为过渡格式，因为这可以减少上传的大小，同时保留最高音质。在使用任何第三方软件或网络服务之前，请务必仔细了解。有些网站在你上传文件后会保留这些文件，有些甚至会将文件提供给其他用户。

文件转换为所需格式后，你应该试听一下，以确保音质可接受且整个文件都已转换。

视频格式

MP4

MP4 导出会创建一个随音频播放而滚动的乐谱视图。除了音频的采样率和比特率设置外，还有常见视频分辨率的设置。参见 导出视频。

混合格式

MIDI

乐器数字接口（MIDI）是一种成熟的音乐行业标准，用于编码乐谱中的所有音符和乐器，但不包含任何视觉排版信息。MIDI 文件可以在某些媒体播放器中播放，但前提是有合适的软件（或硬件）乐器来实现它。这些文件可以在音序器或其他音乐记谱软件中编辑。

MIDI 文件生成的声音取决于用于播放它的虚拟乐器，因此它在 MuseScore 之外播放时很可能会听起来不同。此外，MIDI 不保留视觉排版，因此该文件在任何记谱程序（包括 MuseScore）中打开时，与原谱相比会看起来大不相同。

导出为 MIDI 时，提供以下选项：

  • 展开反复： 开启时，反复段落在生成的 MIDI 文件中会被展开，从而保持乐谱的播放结构。关闭时，创建 MIDI 文件时会忽略反复，因此反复段落只播放一次。
  • 导出 RPN： 注册参数编号（RPN）是一种 MIDI 消息，允许在标准 128 个 MIDI 控制器之外进行扩展控制。它们用于精确调整诸如弯音灵敏度、微调或其他注册功能等参数。开启时，此选项确保这些扩展消息包含在导出文件中，这对于与某些依赖 RPN 数据的 MIDI 设备或软件的兼容性可能是必需的。

乐谱格式

MusicXML

MusicXML 是一种通用标准，旨在尽可能多地保留原始乐谱的排版。它可以在任何现代记谱软件中打开。MuseScore 4 使用 MusicXML 4.0，尽管某些功能尚待实现。

Braille

盲文就绪格式（BRF）是一种纯文本格式，可以存储供盲人使用的文字或音乐文档。这些文件可以在第三方软件中打开，用电子盲文显示器阅读，或压印到纸上形成凸点。

MuseScore 的盲文文件采用"谱表上下对齐"格式，即每个谱表各有一行独立的盲文，小节在谱表之间垂直对齐，如同印刷乐谱一样。（另一种方式是"逐小节"或"逐段落"格式，即先为第一个谱表写出一个或多个小节，再为下一个谱表写出相同的小节，依此类推，全部写在同一行盲文中。MuseScore 目前不支持这些格式。）MuseScore 的盲文文件使用 ASCII 而非 Unicode 字符编码，因此明眼人在文本编辑器中打开这些文件时只会看到随机的字母和标点符号；你需要安装特殊的盲文字体才能看到点状盲文。

MuseScore 的盲文符合北美盲文管理局的 Music Braille Code 2015，但其许多功能尚待实现。目前，如果你先将乐谱导出为 MusicXML，然后使用第三方的 MusicXML 转盲文工具（例如免费的网页工具 SM Music Braille），可能会得到更好的结果。

MEI

音乐编码倡议（MEI）是一种开放的 XML 格式，用于表示音乐记谱文档的语义结构，并且是作为社区驱动的努力而开发的。MuseScore 对 MEI 的支持侧重于 MEI Basic，这是 MEI 的一个子集，便于使用 MEI 进行数据交换并提高互操作性。MuseScore 从 4.2 版本开始提供 MEI 支持，文档见 此处。
