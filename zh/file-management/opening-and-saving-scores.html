打开与保存乐谱

概述

你可以将乐谱文件存储在本地计算机上，或在线（"云端"）存储到你的 MuseScore.com 账户。如果你还没有账户，可以 免费创建一个。

对于在线保存的乐谱，MuseScore 还会在你的计算机上保留本地副本，因此即使没有有效的互联网连接，你也可以继续处理它们。每次保存"云端乐谱"时，musescore.com 上的在线副本也会随之更新。该系统既保护了本地云端乐谱的完整性，又提供了在线存储的所有优势，包括备份、跨多设备查看和播放、便于分享、评论等等。

请注意，如果你从 musescore.com 下载你的某个云端乐谱并在 MuseScore 中打开它，你下载并打开的文件将是一个新的、本地存储的文件，与云端的文件相互独立。

打开乐谱

在 MuseScore 4 中有几种打开乐谱的方法。

文件 → 打开

这会触发你的文件浏览器，允许你选择并打开存储在计算机或存储设备上的乐谱（对话框会因操作系统而异）。\ Windows/Linux：Ctrl+O。macOS：Cmd+O

文件 → 打开最近

此选项允许你从最近打开的乐谱列表中选择。

主页标签 → 乐谱

此窗口显示你最近修改过的乐谱。双击任意乐谱缩略图即可打开它。你也可以单击 打开其他… 从文件浏览器访问本地存储的乐谱。

已保存到云端的乐谱会带有云朵图标。与本地乐谱不同，无法从计算机的文件浏览器重命名或以其他方式修改云端文件。不过，你可以在 musescore.com 的乐谱管理器中执行此操作。单击"乐谱"窗口中的 乐谱管理器（在线） 按钮即可直接转到你的乐谱管理器。

可以同时打开多个乐谱。在这种情况下，MuseScore 会在单独的窗口中打开每个乐谱。

导入文件格式

除了其 原生格式文件（*.mscz 和 *.mscx）之外，MuseScore 还可以打开 MusicXML、压缩的 MusicXML 和 MIDI 文件，以及各种其他 格式 的文件。你可以通过进入 偏好设置 → 导入 来自定义各种导入设置。

保存乐谱

要保存乐谱：

1. 进入 文件\ 2. 选择以下任意选项：

选项 作用 快捷键
保存 将当前乐谱保存到新文件，或将更改保存到之前已保存的文件 Windows/Linux：Ctrl+S，macOS：Cmd+S
另存为... 将当前乐谱保存到新文件 Windows/Linux：Shift+Ctrl+S，macOS：Shift+Cmd+S
保存副本... 将当前乐谱保存到新文件，但允许你继续编辑原始文件 无
保存选区... 将选中的小节保存到新文件 无
保存到云端... 将乐谱作为新文件保存到 musescore.com 无

首次使用上述任一 保存 选项时，会打开一个对话框，询问你"希望如何保存"，然后提供"保存到云端"或"保存到计算机"两个选项。

要禁用此窗口，请单击 不再显示，以确保后续保存时只显示操作系统的原生保存对话框。

保存到计算机

保存到计算机 选项会触发操作系统的"保存"对话框，允许你将乐谱保存为（压缩的）MuseScore 文件 .mscx。

在"保存"对话框中还有一个选项，可以以未压缩格式（"未压缩 MuseScore 文件夹"）保存文件。此选项会在你的计算机上创建一个新文件夹，其中包含一个 MuseScore（.mscx）文件，以及一个缩略图文件（.png）和任何相关的 .json、.mss 和 .xml 文件。

保存到云端

在线（保存到云端）的乐谱会出现在程序的 主页：乐谱 标签中，文件图标一角带有云朵符号。本地副本也会自动保存在你的计算机上。

要将乐谱保存到云端，请选择 保存到云端。这会触发一个对话框，其中包含以下选项：

名称

这是你的乐谱在 musescore.com 上可被识别的名称。

可见性

  • 私密 允许你保存对乐谱的更改，而不会让他人在线看到你的作品。
  • 公开 使你的乐谱对 musescore.com 上的所有人可见。

准备就绪后，单击 保存。首次执行此操作时，MuseScore 会询问你是否也想将音频上传到 musescore.com。你可以从以下选项中选择：

从不

每次按 保存 时，只有乐谱本身会被上传到 musescore.com。在线播放将使用 MS Basic 音色库。

总是

每次按 保存 时，MuseScore 都会生成一个 .mp3 文件与你的乐谱一起上传。musescore.com 上的乐谱播放将与桌面应用中的效果一致（包括 Muse Sounds 音色库的音频（如果已安装），或你添加的任何 VST 乐器和效果器）。

每 x 次保存

MuseScore 只会在你指定的保存间隔生成并上传 .mp3 文件。

这些设置只影响你的私密云端乐谱。此设置只需设置一次，但你随时可以通过进入 偏好设置 → 云端 来更改。单击 确定 后，MuseScore 会确认你的乐谱已保存。你的文件可以从 主页 标签以及 musescore.com 的乐谱管理器中访问。
